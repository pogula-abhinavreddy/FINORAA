# FINORAA 💰
### Quiet Intelligence for Modern Finance

> An AI-powered personal finance tracker that helps you budget smarter, track expenses, and get intelligent investment suggestions — all in one place.

🌐 **Live Demo:** [finoraa18.vercel.app](https://finoraa18.vercel.app)

---

## ✨ Features

- 📊 **Expense Tracking** — Log and categorize your daily transactions effortlessly
- 🤖 **AI Financial Assistant** — Get personalized budgeting advice and insights powered by AI
- 💡 **Investment Suggestions** — Receive smart, data-driven investment recommendations
- 📈 **Visual Analytics** — Understand your spending patterns through intuitive charts
- 🎯 **Budget Goals** — Set monthly budgets and track your progress in real time
- 🔔 **Smart Alerts** — Get notified when you're approaching spending limits

---

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18.x
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/pogula-abhinavreddy/FINORAA.git

# Navigate to project directory
cd FINORAA

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Add your API keys to .env

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🤖 AI Integration

FINORAA leverages **Anthropic's Claude API** to provide:
- Natural language Q&A about your finances
- Personalized budgeting recommendations based on spending history
- Investment suggestions tailored to your financial goals
- Anomaly detection in spending patterns
